# آب‌پاشی تیرگان · Tirgan Splash — 第一屏

《箭魂》游戏式营销第一屏。零后端，纯静态。

---

## 部署

**目标地址**：`https://rastwang.github.io/rastfilm/tirgan/`

**步骤（不用 git，网页操作）**

1. 打开 `https://github.com/rastwang/rastfilm`
2. 点 **Add file → Upload files**
3. 把整个 `tirgan` 文件夹拖进去（GitHub 会保留目录结构）
4. 底部 **Commit changes**
5. 等 1–2 分钟，访问 `https://rastwang.github.io/rastfilm/tirgan/`

**如果显示 404**：仓库 Settings → Pages，确认 Branch 是 `main` / 根目录。

---

## 三条纪律

1. **主站不挂游戏入口。** 游戏是暗门，只从短视频、社媒、二维码直达。
2. **游戏页不出现电影海报、不出现排片、不出现"点击购票"。** 只有那道金线。
3. **两份视觉不混用。** 公仔形象不进电影海报，雪顶金线不进游戏首页。

## 交互逻辑

| 动作 | 发生什么 |
|---|---|
| 点一下 | 小水花 + 计数器 +1 + 泼水声 |
| 手指划过 | 沿轨迹拉水痕 + 水珠顺划动方向飞出 + 音效按概率切换 |
| 划过角色 | 角色缩一下 + 播"哎"/"提尔甘快乐"/笑声（520ms 节流） |
| 水珠甩到屏幕 | 少量粘在"玻璃"上，30% 缓慢下滑留水线 |
| 每 17–30 秒 | 天上一道金线划过（《箭魂》唯一植入） |
| 首次点击 | 解锁音频，启动背景群笑层 |

**速度决定力度**：划得越快，水花越大、越多。

## 调参位置

全在 `index.html` 底部的 `<script>` 里：

- `MAX_DROPS` — 空中水珠上限（默认 460，卡就调小）
- `spawnSplash()` 里的 `14 + power * 30` — 每次划动的粒子数
- `lastSfx > 165` — 泼水音效节流（毫秒）
- `lastHitSfx < 520` — 命中角色音效节流
- `17000 + Math.random() * 13000` — 金线间隔
- `react()` 里的概率分布 — 命中时播哪种声

配色在 CSS 顶部：`#120c07`（底）、`#ffd89a`（金）、`#f3e8d2`（字）。
